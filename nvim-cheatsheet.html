⚡ Flash — Pular para Qualquer Lugar
n/x/o sFlash jump — pular para texto
n/x/o SFlash treesitter — pular por nó
o rFlash remote — operator remoto
o/x RFlash treesitter search
Como usar o jump
Pressione s → comece a digitar o texto → rótulos aparecem sobre os matches → pressione o rótulo para pular
⚠ s substitui o "substitute char" nativo. Use cl no lugar.

󰊢 Símbolos Git (Neo-tree / Gitsigns)
Ícones na árvore de arquivos
?Untracked — git não rastreia este arquivo (falta git add)
MModified — arquivo tem mudanças não commitadas
AAdded / Staged — arquivo adicionado ao index (git add feito)
DDeleted — arquivo deletado no git
U / !Conflito de merge — precisa resolver manualmente
Ícones na margem (gutter) do buffer
│ verdeLinha adicionada
│ azulLinha modificada
_ vermelhoLinha removida
󰘦 Símbolos LSP (Diagnósticos)
Ícones no gutter e na árvore
󰅚 vermelhoErro — sintaxe, tipo, referência inválida
󰀪 amareloWarning — possível problema, mas não crítico
󰌶 azulHint — sugestão do LSP (import não usado, etc.)
󰋽 cyanInfo — informação do LSP
Se aparecer quadrado □ ou ponto estranho
Fonte Hack Nerd Font não instalada ou não selecionada no terminal. Os ícones são Unicode especiais da Nerd Font.
󰑐 Recarregar sem Reiniciar
R no Neo-treeAtualiza a árvore de arquivos
:eRecarrega o buffer atual do disco
:checktimeVerifica se arquivos mudaram externamente
autoread + checktime estão configurados em vim-options.lua — o Neovim recarrega automaticamente ao ganhar foco.
