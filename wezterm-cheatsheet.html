󰆍 WezTerm Cheat Sheet

ericsts · ~/.wezterm.lua

Leader = Ctrl + a  (timeout 1s)
󰕮 Splits — Dividir Painel
Ctrl+a |Split vertical (lado a lado)
Ctrl+a -Split horizontal (cima/baixo)
Ctrl+a xFechar pane atual (pede confirmação)
Ctrl+a zToggle zoom — maximiza/restaura pane
󰆏 Navegação entre Panes
Ctrl+a hIr para o pane da esquerda
Ctrl+a jIr para o pane de baixo
Ctrl+a kIr para o pane de cima
Ctrl+a lIr para o pane da direita
󰙖 Redimensionar Panes
Ctrl+a HExpandir para a esquerda (+5)
Ctrl+a JExpandir para baixo (+5)
Ctrl+a KExpandir para cima (+5)
Ctrl+a LExpandir para a direita (+5)
Shift + hjkl (maiúsculas). Cada pressão move 5 células.
󰓩 Tabs
Ctrl+a cCriar nova tab
Ctrl+a nIr para a próxima tab
Ctrl+a pIr para a tab anterior
Ctrl+a wPopup com lista de todas as tabs
Ctrl+a ,Renomear a tab atual
󰭎 Command Palette
Ctrl+a PAbrir Command Palette — busca qualquer ação do WezTerm
Como usar
Digite parte do nome da ação (ex: "split", "tab", "font") e pressione Enter para executar. Dispensa lembrar atalhos.
󰆒 Quick Select — Copiar sem Mouse
Ctrl+a sAtivar Quick Select
Como usar
Detecta automaticamente na tela: URLs, git hashes, caminhos de arquivo, IPs, números. Uma letra aparece sobre cada item — pressione a letra para copiar para o clipboard instantaneamente.
󰓎 Workspaces — Sessões Independentes
Ctrl+a WListar e trocar de workspace
Ctrl+a $Criar ou ir para workspace pelo nome
Ctrl+a ERenomear o workspace atual
Como usar
Cada workspace tem suas próprias tabs e panes, completamente isolados. Exemplo: workspace "laravel" com nvim + servidor + artisan, workspace "dotfiles" com outro ambiente separado. Trocar de workspace não fecha nada — tudo fica rodando em background.
󰁯 Sessões — Persistência entre Reinicializações
Automático (plugin resurrect)
Salva automaticamente a cada 5 minutos e ao fechar o WezTerm. Ao reabrir, restaura o último workspace automaticamente.
Manual
Ctrl+a SSalvar sessão do workspace atual agora
Ctrl+a RRestaurar sessão salva (abre picker)
󰍽 Mouse
Ctrl + CliqueAbrir link sob o cursor
