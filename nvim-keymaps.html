⚙ Geral & Splits
Arquivo
<leader>ya Copiar arquivo inteiro para clipboard
Navegação entre splits
CtrlH / CtrlL Split esquerdo / direito
CtrlJ / CtrlK Split abaixo / acima
Gerenciar janelas (Vim nativo)
CtrlWv Split vertical
CtrlWs Split horizontal
CtrlWq Fechar janela atual
CtrlW= Equalizar tamanhos
CtrlWo Fechar todas menos a atual
Outros nativos úteis
CtrlA / CtrlX Incrementar / decrementar número
u / CtrlR Desfazer / Refazer
gg / G Início / fim do arquivo
% Pular para par de bracket/paren
* / # Buscar palavra sob cursor (↓ / ↑)
ci" ci( … Substituir conteúdo entre delimitadores
yiw / diw Yank / delete palavra sob cursor
. Repetir último comando
zz Centralizar linha atual na tela
za Toggle fold (dobrar/expandir código)

⚡ LSP — Language Server Protocol
Navegação
gd Ir para definição
gD Ir para declaração
gR Ver todas as referências (Telescope)
gi Ver implementações (Telescope)
gt Ver type definitions (Telescope)
K Mostrar documentação (hover)
Ações
<leader>ca Code actions (normal e visual)
<leader>rn Renomear símbolo
<leader>gf Formatar arquivo (via LSP)
<leader>rs Reiniciar LSP
Diagnósticos
<leader>d Diagnóstico da linha atual (float)
<leader>D Todos diagnósticos do buffer (Telescope)
[d / ]d Diagnóstico anterior / próximo
Gerenciadores
:Lazy Gerenciar plugins — I instala, U atualiza, X remove
:Mason Gerenciar LSPs/tools — i instala, X desinstala
:LspInfo Status dos servidores LSP ativos
